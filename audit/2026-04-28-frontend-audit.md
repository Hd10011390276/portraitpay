### 1.2 问题

| 优先级 | 问题 | 描述 |
|--------|------|------|
| 🔴 高 | **Sepolia 测试网标注** | 首页大标题写"已上线 Ethereum Sepolia 测试网"——普通用户看到这个会以为还要学加密货币。建议改为更中性的描述，如"已支持区块链存证" |
| 🔴 高 | **KYC 文案误导** | Step 2写"完成 KYC"+"验证身份，解锁企业授权功能"——用户会觉得一上来就要做 KYC。建议：普通用户第一步不需要 KYC，只有要mint/上链才需要 |
| 🟡 中 | **定价页"¥0/永久"歧义** | 免费版显示¥0/永久，容易让用户误解定价为0。建议改为"¥0起/永久"或明确说明条件 |
| 🟡 中 | **注册按钮 CTA 不够突出** | "免费开始"在页面深处，建议在 Hero 区就放一个明显的 CTA |
| 🟢 低 | **How it Works 动画缺失** | 4步流程目前是静态展示，可以加微动画让用户直观看到流程 |
| 🟢 低 | **Features 图标统一性** | Features 区域图标风格不一致，建议统一 |

## 二、注册页 (/register)

### 2.1 内容亮点
✅ **隐私选项设计很好**：允许/禁止授权场景的勾选，肖像使用偏好设置完整

### 2.2 问题

| 优先级 | 问题 | 描述 |
|--------|------|------|
| 🔴 高 | **注册要选"角色"** | 用户刚来就要选角色（普通用户/律师/机构），门槛太高。建议：先注册，角色在上传第一个肖像时再提示选择 |
| 🔴 高 | **"允许授权"默认开启** | 默认勾选"允许肖像授权"，新增用户可能不清楚含义就注册了。建议：默认关闭，提示用户了解后再开启 |
| 🟡 中 | **禁止使用场景全选** | 政治/反动、暴力/血腥、仇恨/歧视、违法行为——这些用词太泛。建议：参考行业标准，精确描述 |
| 🟡 中 | **KYC 手机号可选** | 但注册表单本身没有说明 KYC 在哪个环节触发，用户会困惑"我现在做的KYC是什么级别的" |
| 🟢 低 | **注册后没有引导** | 注册完成后直接跳转，没有引导用户下一步该做什么（尤其是第一个肖像上传的引导） |

## 七、核心产品路径体验问题

### 7.1 用户旅程断裂

当前路径：
```
注册 → Dashboard → (不知道下一步) 
```

建议路径（符合商业企划书）：
```
首页 → 注册 → 引导上传肖像 → 完成第一个肖像上传 → 引导mint(区块链认证) → 完成授权合同 → 律师服务
```

**缺失的引导：**
- 注册完成后没有任何引导提示
- Dashboard 里没有"下一步该做什么"的 onboarding
- 新用户第一个肖像上传后，没有引导去 mint

### 7.2 最严重：缺少"AI数字人授权合同"入口

**这是商业企划书的核心功能，但首页和用户面板里完全找不到"签署授权合同"的入口！**

用户路径应该是：
1. 完成肖像认证（mint）
2. 选择合同模板（Standard/Exclusive/Endorsement/Film Adaptation）
3. 填写授权内容
4. 签署合同（律师审查）
5. 等待授权费到账

但现在产品里完全没有这个流程。
